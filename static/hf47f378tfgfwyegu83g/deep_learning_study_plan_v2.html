🎯 Semester 1 Project

Vision-Based Terrain Classification for Quadruped Locomotion

  • Train a CNN to classify terrain from camera (flat/rough/stairs/slopes)
  • Integrate with IsaacLab - feed predictions to your RL policy
  • Compare: blind policy vs vision-guided policy performance
  • Implement real-time inference pipeline in simulation

💡 How to Succeed in Semester 1

  • Watch at 1.5x: Justin's teaching is crystal-clear
  • Do assignments without solutions first: Struggle builds understanding
  • Derive gradients by hand: Essential for backprop intuition
  • Connect to RL: Notice policy gradient ↔ gradient descent parallels
  • Weekly: 3 lectures (6hrs), 1 assignment section (8hrs), reading (3hrs), project (3hrs)

🎯 Semester 2A Project

Self-Supervised Terrain Representation Learning

  • Use contrastive learning (SimCLR/MoCo) on unlabeled terrain images
  • Learn robust visual features without manual annotations
  • Transfer to downstream tasks: terrain classification, depth estimation
  • Compare: supervised vs self-supervised feature quality for RL policies

🎯 Semester 2B Project

Language-Conditioned Quadruped Control

  • Fine-tune a small transformer (BERT/DistilBERT) to understand locomotion commands
  • Map commands → action parameters: "walk slowly uphill", "trot on flat ground"
  • Build multi-modal policy: text encoder + vision encoder + control network
  • Test in IsaacLab with natural language task specifications

🤖 NLP Applications for Robotics:

• Instruction following ("navigate to the red box")

• Trajectory description generation for logging

• Attention for multi-sensor fusion

• Sequence-to-sequence for motion planning

💡 Study Tips for University-Paced Learning

  • Implement everything from scratch first: Then use libraries
  • Derive all math: Gradients, loss functions, backprop - by hand
  • Debug intensely: University courses expect you to struggle
  • Use office hours: Course forums, Discord communities, GitHub discussions
  • Build in public: Blog posts, GitHub repos, Twitter threads
  • Paper reading: 1-2 papers/week minimum
